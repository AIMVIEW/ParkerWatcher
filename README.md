# ParkerWatcher

ParkerWatcher คือระบบตรวจสอบช่องจอดรถอัตโนมัติ โดยใช้รถขนาดเล็กเคลื่อนที่ตามเส้นด้วยเซนเซอร์ IR เพื่อตรวจสอบช่องจอดแต่ละช่อง และใช้ Ultrasonic Sensor วัดระยะเพื่อตรวจว่าช่องจอดว่างหรือมีรถจอดอยู่

ข้อมูลสถานะของช่องจอดจะถูกส่งผ่าน Wi-Fi ไปยังระบบจัดเก็บข้อมูล และแสดงผลบนเว็บไซต์ โดยผู้ใช้สามารถดูตำแหน่งและสถานะของแต่ละช่อง รวมถึงจำนวนช่องจอดที่ว่างได้

เมื่อผ่านไประยะเวลาที่กำหนด รถจะวนกลับมาตรวจสอบช่องจอดอีกครั้งเพื่ออัปเดตสถานะให้เป็นปัจจุบัน


## เว็บไซต์

ดาวน์โหลด repository แล้วแตก ZIP จากนั้นเปิด [index.html](index.html) ได้เลย ไม่ต้องติดตั้งแพ็กเกจ หน้าเว็บมีหัวข้องาน ปุ่ม Connect ผังจอดแถวเดียวด้านบน และจำนวนที่ว่าง โดยเส้นทางรถสำรวจขนานกับแถวจอด

ใช้ฟอนต์ Prompt ที่เก็บไว้ใน `vendor/fonts/prompt/` พร้อมใบอนุญาต SIL Open Font License 1.1 ไม่ต้องโหลดฟอนต์จาก CDN

แก้ Broker และ Topic ใน [config.js](config.js) ให้ตรงกับ Arduino แล้วกด Connect

## รูปแบบ MQTT

ใช้ Topic เดียว เช่น `parkerwatcher/lot01/slots` และส่ง JSON array ครบทุกช่อง:

```json
[1,0,1,0,1,1]
```

`1` = มีรถ, `0` = ว่าง, `null` = ยังไม่ทราบ ตำแหน่งแรกเป็น A1 ตามด้วย A2 ไปเรื่อย ๆ ตัวอย่างนี้มี 6 ช่อง ว่าง 2 ช่อง จำนวนกล่องปรับตามความยาว array อัตโนมัติ (ก่อนรับข้อมูลแสดง 4 ช่อง)

ส่งด้วย Retain=false เพราะ array ไม่มีเวลาตรวจ เมื่อข้อมูลเก่าหรือขาดการเชื่อมต่อจะไม่แสดงจำนวนว่างเป็นข้อมูลปัจจุบัน

รายละเอียดการเชื่อมต่อ ตัวอย่าง Arduino และแนวทางเพิ่มช่องอยู่ใน [MQTT.md](MQTT.md)

