# ParkerWatcher

## เว็บไซต์

- เว็บไซต์โปรเจกต์: https://aimview.github.io/ParkerWatcher/
- Dashboard: https://aimview.github.io/ParkerWatcher/mqttWebsite/

## บทคัดย่อ

ParkerWatcher คือหุ่นยนต์สำรวจช่องจอดรถ โดยใช้ Arduino UNO R4 WiFi เป็นตัวควบคุม รถเคลื่อนที่ตามเส้นด้วยเซนเซอร์ IR และใช้ Ultrasonic HC-SR04 วัดระยะเพื่อประเมินว่าช่องจอดว่างหรือมีรถจอดอยู่ จากนั้นส่งข้อมูลผ่าน Wi-Fi และ MQTT ไปแสดงบนเว็บไซต์ ซึ่งแสดงสถานะของแต่ละช่องและจำนวนช่องจอดที่ว่างได้ โดยออกแบบให้รถหมุนกลับและเริ่มตรวจรอบใหม่ เพื่อช่วยลดความไม่สะดวกในการขับรถวนหาที่จอด

## หลักการทำงาน

1. รถอ่านเซนเซอร์ IR เพื่อเดินตามเส้น และนับจุดตรวจเมื่อเซนเซอร์ทั้งสองพบสีดำ
2. จุดที่ 1–3 รถหยุดและใช้ Ultrasonic วัดระยะเพื่อประเมินสถานะช่องจอด A1–A3
3. ส่งสถานะครบทั้งสามช่องผ่าน MQTT โดย `1` = มีรถ, `0` = ว่าง และ `null` = ยังไม่ทราบ
4. เว็บไซต์อัปเดตสถานะของแต่ละช่องและนับจำนวนที่ว่างเฉพาะค่า `0`
5. เมื่อตรวจครบ 3 ช่อง รถหมุนกลับ ผ่านจุดที่ 4–6 โดยไม่ตรวจหรือส่งผลใหม่ แล้วหมุนกลับ เริ่มนับรอบใหม่

ตัวอย่าง `[1,0,null]` หมายถึง A1 มีรถ A2 ว่าง และ A3 ยังไม่ทราบสถานะ รวมว่าง 1 จาก 3 ช่อง

## อุปกรณ์หลัก

- Arduino UNO R4 WiFi
- Arduino Sensor Shield จำนวน 1 ตัว
- IR TCRT5000 จำนวน 2 ตัว
- Ultrasonic Sensor รุ่น HC-SR04 จำนวน 1 ตัว
- L298N
- มอเตอร์ DC จำนวน 2 ตัว
- โครงรถ ล้อ แหล่งจ่ายไฟ และสายเชื่อมต่อ

## วิธีติดตั้งและใช้งาน

1. ดาวน์โหลด repository และเปิด `Watcher.ino` ด้วย Arduino IDE
2. เลือกบอร์ด Arduino UNO R4 WiFi และติดตั้งไลบรารี MQTT by Joel Gaehwiler
3. กรอกชื่อและรหัสผ่าน Wi-Fi ในโค้ด แล้วอัปโหลดลงบอร์ด
4. เปิด Dashboard แล้วกด Connect โดยใช้ Broker `mqtt-dashboard.com` และ Topic `parkerwatcher/lot01/slots`
5. วางรถบนสนาม แล้วกดสวิตช์ตรงกลางตัวรถเพื่อเริ่มทำงาน
