# ParkerWatcher

ParkerWatcher คือระบบตรวจสอบช่องจอดรถอัตโนมัติ โดยใช้รถขนาดเล็กเคลื่อนที่ตามเส้นด้วยเซนเซอร์ IR เพื่อตรวจสอบช่องจอดแต่ละช่อง และใช้ Ultrasonic Sensor วัดระยะเพื่อตรวจว่าช่องจอดว่างหรือมีรถจอดอยู่

ข้อมูลสถานะของช่องจอดจะถูกส่งผ่าน Wi-Fi ไปยังระบบจัดเก็บข้อมูล และแสดงผลบนเว็บไซต์ โดยผู้ใช้สามารถดูตำแหน่งและสถานะของแต่ละช่อง รวมถึงจำนวนช่องจอดที่ว่างได้

เมื่อผ่านไประยะเวลาที่กำหนด รถจะวนกลับมาตรวจสอบช่องจอดอีกครั้งเพื่ออัปเดตสถานะให้เป็นปัจจุบัน


## หลักการทำงาน

1. รถอ่านเซนเซอร์ IR เพื่อเดินตามเส้น เพื่อระบุตำแหน่งช่องจอด
2. Ultrasonic วัดระยะ แล้วแปลงเป็นสถานะ มีรถ ว่าง หรือ ยังไม่ทราบ
3. เก็บสถานะเรียงตาม A1, A2, … และส่ง array ครบทุกช่องผ่าน MQTT
4. เว็บไซต์อัปเดตช่องจอดและนับจำนวนที่ว่าง

ตัวอย่าง `[1,0,null,0]` หมายถึง 4 ช่อง ว่าง 2 ช่อง โดย `1` = มีรถ, `0` = ว่าง และ `null` = ยังไม่ทราบ

## อุปกรณ์หลัก

- Arduino UNO R4 WiFi
- IR TCRT5000 จำนวน 2 ตัว และ Ultrasonic Sensor รุ่น HC-SR04
- L298N และมอเตอร์ DC จำนวน 2 ตัว
- โครงรถ ล้อ แหล่งจ่ายไฟ และสายเชื่อมต่อ
